What we learned

The verifier flags fixes that silence checkers.

Two fixes passed their tests but added a lint or type-check suppression. The verifier flagged both for review; Devin removed the suppressions and both fixes were proven again without them.

A gap in the verifier sent one bug to an engineer, and a one-line fix brought it back.

The verifier did not recognise Superset's *_tests.py test files, so the first fix for #4 could not be proven and hit the retry limit. After the fix, the retry was proven: 6 of 1,210 tests fail before, all pass after.

Devin speaks for the work; the service only moves labels and statuses.

Every comment on these bugs comes from Devin's own GitHub account.

Polling every bug each minute is expensive.

Re-reading every tracked bug and pull request once a minute used a token's 5,000 GitHub requests an hour. Webhooks or conditional requests are the next step.
